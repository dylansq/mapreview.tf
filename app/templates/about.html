About
Welcome to TF2 Map Review (fka. mapreview.tf) - a searchable repository of competitive TF2 map reviews, tactics guides, and other resources published by the Team Fortress 2 community. If you have a new (or old) resource to add, you can submit a resource.

This site was created by Zebulon, with thanks to Blake++ RoGue for contributions and help keeping the site running! Some parts are still under development. If you find any issues please send them to the contact below.
Contact
If you would like to get in contact, you can join the mapreview.tf discord or submit a bug report via discord.
Donate
If you find this useful, please consider donating to support this project! All server costs are community supported and your help will ensure this resource is available for others in the future.
